# Nimlo 0.2.2

A lightweight code editor with a shared workspace, persistent terminal, and on-demand AI through your installed Codex or Claude CLI.

## Downloads

| Platform | Download | Interface |
| --- | --- | --- |
| macOS 13.3+, Apple silicon | `Nimlo-0.2.2-macos-arm64.zip` | Native Mac app |
| macOS 13.3+, Intel | `Nimlo-0.2.2-macos-x64.zip` | Native Mac app |
| Linux x64, glibc 2.35+ | `Nimlo-0.2.2-linux-x64.tar.gz` | Browser host |
| Linux ARM64, glibc 2.35+ | `Nimlo-0.2.2-linux-arm64.tar.gz` | Browser host |
| Windows 10/11 x64 | `Nimlo-0.2.2-windows-x64.zip` | Browser host |
| Windows 11 ARM64 | `Nimlo-0.2.2-windows-arm64.zip` | Browser host |

The Mac downloads contain `Nimlo.app`. Drag it to Applications. These builds are ad-hoc signed and are not Apple-notarized; macOS may require explicit approval before opening them. Install them manually. The existing signed update channel is managed separately.

Linux and Windows downloads contain the host executable, a launcher, and usage instructions. The editor opens in your existing browser; a project and its terminal run on the host PC. Windows hosts are experimental: Windows filesystem race and process-tree protections have not received the Unix-specific security validation described in `SECURITY.md`. Android and iOS use the browser client by pairing with a running host.

Each platform is built and tested on a matching GitHub-hosted runner. `SHA256SUMS.txt` records the SHA-256 digest of every download. AI provider CLIs and the optional `cloudflared` internet connector are installed separately.

## Quick start

- **Mac:** extract the ZIP, drag `Nimlo.app` to Applications, open it, and choose **Open folder…**. For first-launch approval, see [Apple's instructions](https://support.apple.com/en-us/102445).
- **Windows:** extract the ZIP, open PowerShell inside the extracted folder, and run:

  ```powershell
  & ".\Start Nimlo.cmd" --workspace "C:\Projects\my-app"
  ```

- **Linux:** extract the archive, open a terminal inside the extracted folder, and run:

  ```sh
  ./nimlo-editor --workspace "$HOME/projects/my-app" --open-browser
  ```

Replace the example path with your project folder. Keep the Windows/Linux host terminal running. Use **Files → Find file…** to open a file, **⌘S / Ctrl+S** to save, and **Terminal** to run project commands.

To connect a phone over the internet, install [cloudflared](https://developers.cloudflare.com/tunnel/downloads/) on the PC, then choose **Session → Pair a device → Create internet link**. Open the complete invitation link on the phone and enter the six-digit code. Keep the PC awake and Nimlo running.

[Full quick-start guide and phone screenshots](https://github.com/guilhermegm/Nimlo#quick-start).
