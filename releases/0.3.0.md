# Nimlo 0.3.0

Nimlo is a native Mac editor powered by **Neovim 0.12.6**, with shared project files, persistent host terminals, and AI through installed provider CLIs.

## Download

**Apple silicon · macOS 13.3 or later:** `Nimlo-0.3.0-macos-arm64.zip`

The archive contains **Nimlo.app**, including Neovim and its runtime. Extract it, drag the app into Applications, and choose **Open folder…**. The app is ad-hoc signed and not Apple-notarized; see [Apple's first-launch guidance](https://support.apple.com/en-us/102445) if macOS blocks it. Install updates manually. `SHA256SUMS.txt` records the download's SHA-256 digest.

## Get started

- **Open a file:** use the native sidebar or **⌘P**.
- **Edit normally:** keep **Edit** selected. Choose **Vim** for Neovim's modal navigation, selections, commands, and macros.
- **Save / find:** **⌘S** saves; **⌘F** searches within the current file.
- **Use tools:** **AI** opens beside the editor and **Terminal** opens below it, in the same window.
- **Connect a phone:** install [cloudflared](https://developers.cloudflare.com/tunnel/downloads/) on the Mac, choose **Share → Create internet link**, then open the complete invitation on the phone and enter its six-digit code.

[Quick-start guide and screenshots](https://github.com/guilhermegm/Nimlo/blob/v0.3.0/README.md#quick-start).

Personal Neovim plugins are isolated from the app. The phone uses the browser client with the same host files and tools. Physical input methods, accessibility, and long-running behavior need further validation. This native release supports Apple silicon Macs.
