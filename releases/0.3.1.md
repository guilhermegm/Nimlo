# Nimlo 0.3.1

Nimlo now shows persistent in-app update notifications for published GitHub releases.

- Checks for stable, compatible updates automatically while running.
- Keeps the update banner visible across app restarts and offline checks.
- Adds **Nimlo → Check for Updates…** for manual checks.
- Opens the official release page from **Download update…**, while keeping the current workspace running.
- Publishes future updates automatically when a prepared version tag is pushed.

**Users on 0.3.0 must install 0.3.1 manually once to enable future notifications.** Download `Nimlo-0.3.1-macos-arm64.zip`, extract it, quit Nimlo, and replace the app in Applications. Updates are installed manually; the app does not replace itself or force a restart.

Apple silicon · macOS 13.3 or later · bundled Neovim 0.12.6. This build is ad-hoc signed and not Apple-notarized. `SHA256SUMS.txt` records the download's digest.

The update system is tested with malformed and incompatible releases, offline responses, rate limiting, cache persistence, and actual native UI checks that preserve unsaved work. [Quick start and update instructions](https://github.com/guilhermegm/Nimlo/blob/v0.3.1/README.md#update-notifications).
